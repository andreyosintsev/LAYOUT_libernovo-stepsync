Вопросы и ответы

Для чего предназначена подставка для ног к креслу LiberNovo Omni
Подставка для ног к креслу LiberNovo Omni имеет две высоты: 7,1 см — для пользователей ростом 170–200 см и 11,9 см — для пользователей ростом 153–169 см. Она рассчитана на стандартную высоту стола 75 см и обеспечивает эргономичную посадку. Подставка повышает удобство при сидении, адаптируясь к росту пользователя.
Подставка поставляется вместе с креслом LiberNovo?
Подставка для ног не входит в стандартную комплектацию кресла и продаётся отдельно.
Чем отличаются варианты исполнения подставки для ног к креслу LiberNovo Omni?
Подставки для ног различаются цветом. Все подставки подходят любых моделей кресел LiberNovo. Разные варианты разработаны прежде всего для того, чтобы сочетаться по цвету с соответствующими моделями кресел. Если сочетание цветов для вас не принципиально, вы можете выбрать любой понравившийся вариант.
