# LiberNovo StepSync

Проект LiberNovo StepSync- лендинг-страницы для приобретения подставок для ног для эргономичных офисных кресел. В качестве основы взят англоязычный сайт производителя, но верстка блоков и страницы в целом выполнено независимо от исходника.

Всего в лендинге представлено 3 модификаций данной модели в разных цветах.
Переведена вся графика для всех вариантов модели и реализовано переключение цветов подставок для ног при помощи селектора.

## Технологии

В этом проекте использованы следующие технологии:

- **HTML/CSS** — для создания и стилизации интерфейса
- **JavaScript** — для интерактивных элементов
- **JQuery** — для создания каруселей
- **OwlCarousel 2** — для создания каруселей
- **PHP/mail()** отправка уведомлений о размещении заявки на сайте

- **Адаптивный дизайн:** любое разрешение браузера, мобильное меню.
